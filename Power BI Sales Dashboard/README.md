# Sales Performance & Profit Analysis Dashboard

## Project Overview

This project is an interactive **Power BI Sales Analytics Dashboard** designed to analyze sales performance, revenue, profitability, customers, products, and business segments.

The dashboard transforms sales data into actionable insights using interactive visualizations, KPIs, filters, trend analysis, and customer-level drill-through analysis.

## Objectives

* Analyze overall sales and profit performance
* Identify top-performing products and customers
* Track sales and profit trends over time
* Compare performance across customer segments and regions
* Analyze revenue, profit margin, and contribution margin
* Provide customer-level insights through drill-through analysis

##  Dashboard Features

###  Summary

Provides a high-level overview of key sales and business performance metrics.

###  Sales Trend Analysis

* Monthly and yearly sales trends
* Period-based analysis
* Interactive date filtering
* Trend comparison across different periods

###  Customer Analysis

* Customer-level sales performance
* Top customers identification
* Customer order analysis
* Customer-specific drill-through functionality

###  Product Analysis

* Product-wise sales comparison
* Most-selling product identification
* Product contribution analysis
* Profit and margin comparison

###  Segment & Region Analysis

* Sales performance by business segment
* Regional performance analysis
* Interactive filtering by segment and region

###  Profit Analysis

* Total profit analysis
* Profit margin %
* Contribution margin %
* Product-wise profitability comparison
* Quarterly profit analysis

## Tools & Technologies

* **Power BI Desktop**
* **DAX**
* **Power Query**
* **Data Modeling**
* **Interactive Data Visualization**
* **Drill-through & Slicers**
* **KPI & Measure Development**

##  Key Power BI Concepts Demonstrated

* Data cleaning and transformation using Power Query
* Data modeling and relationships
* DAX measures and calculated metrics
* Time-based analysis using a Calendar table
* Interactive slicers and filters
* Drill-through pages
* KPI cards
* Trend and comparative analysis
* Business-focused dashboard design
