# Walmart Store Sales Analysis – Excel

## Project Overview

This project analyzes Walmart weekly sales data using **Microsoft Excel** to identify sales trends and understand the relationship between weekly sales and selected economic factors.

The analysis focuses on historical sales performance across different years and quarters and includes statistical and correlation analysis.

## Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Data Analysis
* Descriptive Statistics
* Correlation Analysis
* Trend Analysis
* Data Visualization

## Dataset

The dataset contains **6,400+ weekly sales records** with information including:

* Store
* Date
* Weekly Sales
* Holiday
* Temperature
* Fuel Price
* CPI
* Unemployment

## Analysis Performed

### 1. Sales Trend Analysis

* Analyzed weekly sales across different years.
* Compared sales performance across quarters.
* Identified overall sales trends and variations.

### 2. Statistical Analysis

Performed descriptive statistical analysis on the sales data to understand the distribution and variation in weekly sales.

### 3. Correlation Analysis

Analyzed the relationship between **Weekly Sales** and selected factors:

* Fuel Price
* Temperature
* CPI
* Unemployment

## Key Excel Features Used

* Pivot Tables
* Pivot Charts
* Descriptive Statistics
* Correlation Analysis
* Data Filtering
* Data Visualization
