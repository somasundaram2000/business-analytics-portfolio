# Supermarket Sales Analysis & Dashboard

## Project Overview

Analyzed 1,000+ supermarket sales transactions using Microsoft Excel to identify sales, product, pricing, and customer trends.

## Tools & Skills

* Microsoft Excel
* Pivot Tables
* Data Analysis
* Statistical Analysis
* Data Visualization
* Dashboard Development

## Key Analysis

* Product-line and city-wise sales analysis
* Quantity and unit-price analysis
* Gross income analysis
* Customer rating analysis
* Correlation analysis
* KPI-based sales dashboard
